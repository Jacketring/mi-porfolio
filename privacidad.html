Política de privacidad

Aquí puedes consultar de forma clara cómo se tratan los datos que facilitas mediante el formulario de contacto de este portfolio. Última actualización: 19 de agosto de 2026.

1. Responsable del tratamiento

El responsable es Jose Hurtado de Mendoza. Puedes contactar para cualquier cuestión relacionada con tus datos en josehur2003@gmail.com.

2. Datos que se recogen

El formulario solicita tu nombre, correo electrónico y el mensaje que decidas enviar. No se solicitan categorías especiales de datos personales.

3. Finalidad y base jurídica

Los datos se utilizan exclusivamente para recibir tu consulta, responderla y mantener las comunicaciones necesarias relacionadas con ella. La base del tratamiento es el consentimiento que otorgas al enviar voluntariamente el formulario.

4. Destinatarios y servicio de envío

Los datos no se utilizarán para comunicaciones comerciales ni se cederán a terceros por iniciativa propia. El envío técnico del formulario se gestiona mediante FormSubmit, que actúa como proveedor del servicio. Puedes consultar la política de privacidad de FormSubmit.

5. Conservación

La información se conservará durante el tiempo necesario para gestionar y responder tu consulta y, después, únicamente durante el periodo imprescindible para atender posibles responsabilidades. FormSubmit indica que conserva los envíos durante 30 días.

6. Tus derechos

Puedes solicitar el acceso, rectificación, supresión, oposición, limitación o portabilidad de tus datos, así como retirar tu consentimiento, escribiendo a josehur2003@gmail.com. También puedes presentar una reclamación ante la Agencia Española de Protección de Datos.

7. Seguridad y cambios

Se aplican medidas razonables para evitar el acceso, alteración o pérdida de los datos. Esta política podrá actualizarse si cambia el formulario, el proveedor utilizado o la normativa aplicable.
